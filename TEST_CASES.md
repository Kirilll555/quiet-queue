# Тест-кейсы

Если не указано иное, у каждого примера собственные данные. Для проверок времени базовый момент — понедельник 1 июня 2026 года, 10:30 по Москве. Точные варианты параметров и имена собранных примеров выводит pytest --collect-only.

| № | Подготовка и действие | Ожидаемый результат |
|---|---|---|
| 01 | Создать общую и кабинетную отметки, проверить подписи и обратные связи, удалить кабинет, пользователя, учреждение | Отметки упорядочены от новой. Первые два удаления обнуляют ссылки, последнее удаляет зависимые отметки и кабинеты |
| 02 | Проверить пустые координаты, географические пределы и превышение на 0,000001 | Пустая и граничные пары допустимы, превышение вызывает ошибку валидации |
| 03 | Повторить составной ключ ограничения, затем удалить автора | База отклоняет дубликат. Ограничение удаляется вместе с автором |
| 04 | Открыть регистрацию, ввести слабый пароль, несовпадающее подтверждение или занятый ник | Форма запрашивает только ник и два поля пароля, возвращает ошибку соответствующего поля |
| 05 | Гость отправляет оценку, регистрируется, входит с неправильным и с правильным паролем, выходит | Перенаправление на вход, проверка хеша, возврат на rate, повторная регистрация вошедшего ведёт в каталог. Выход через POST завершает сессию |
| 06 | POST без CSRF на пять форм, запросить четыре списка админки обычным пользователем и администратором | 403 для POST, перенаправление для обычного пользователя, 200 для администратора |
| 07 | Объединить поиск и фильтр, отправить пустую выборку, вывести название с угловыми скобками | Только совпадающие записи, пустое состояние, безопасное HTML-представление |
| 08 | Смешать кабинетные, общие, повторные и анонимные отметки. Поставить отметки ровно на границе часа и на микросекунду раньше | Учитывается последняя свежая от каждого автора в своей очереди. Граница включена. Без данных статус неизвестен |
| 09 | Вычислить статус одной оценки каждого уровня и средние 1,5 и 2,5 | Все три уровня корректны, на порогах выбираются средний и высокий статусы |
| 10 | Передать пустой, нечисловой, отсутствующий ID, чужой кабинет, неподдерживаемый уровень | Понятное сообщение об ошибке, таблица отметок пуста |
| 11 | Отправить допустимую оценку с кабинетом и без него, повторить отправку | Сообщение об успехе и возврат на выбранное учреждение. Повтор отклонён, в базе одна отметка |
| 12 | Подготовить старую отметку без записи ограничения возрастом 899, 900 и 901 секунду | Через 899 секунд отказ, начиная с 900 секунд запись разрешена |
| 13 | Сменить очередь или пользователя; затем одновременно отправить две оценки одного пользователя в одну очередь | Разные очереди и авторы независимы. Одновременные запросы не создают дубликата; после снятия блокировок возможна повторная попытка |
| 14 | Имитировать ошибку вставки оценки, блокировку SQLite и иную ошибку хранилища | Транзакция откатывается. При блокировке посетитель видит сообщение и форму; иная ошибка передаётся вызывающему коду |
| 15 | Передать вчерашнюю дату, чужой кабинет, произвольный текст, перевёрнутые или недопустимые часы | Прогноз возвращает объяснение ошибки. Невозможные и пустые даты отклоняет форма |
| 16 | Выбрать расписание 8:30–12:15 на сегодня и завтра | Сегодня доступно 11:00, завтра 09:00, 10:00, 11:00. Без истории рекомендация отсутствует |
| 17 | Создать историю трёх недель, повторы внутри часа, анонимные, чужие и некорректные записи | Учитываются последние подходящие оценки каждого автора. Проверены средние 1, 1,5 и 2,5 и подписи к ним |
| 18 | Сравнить 4 оценки за 3 даты, 5 за 2 даты и 5 за 3 даты. Два интервала имеют равный балл | Только последняя выборка достаточна, при равенстве выбран ранний интервал |
| 19 | Открыть прогноз с предвыбранным учреждением, выбрать общий или кабинетный вариант | Ограниченная выборка кабинетов, правильная минимальная дата. Результат появляется после валидной отправки |
| 20 | Отправить пустую и заполненную заявку, дважды одобрить заполненную через действие админки | Пробелы обрезаны, до модерации учреждения нет. Первое одобрение добавляет одно учреждение, второе — ноль |
| 21 | Открыть мобильное меню, нажать Escape, включить режим чтения и перезагрузить страницу | Меню сворачивается, фокус на кнопке. Режим сохраняется, каталог помещается в 390 пикселей |
| 22 | Открыть карту без SDK, затем с локальной подменой для 0, 1 и 2 учреждений, переключить ширину на 1280 | Без ключа кнопка недоступна; для пустой выдачи есть подсказка. Одна точка центрируется, несколько вписываются в границы. На широком экране список и карта видны вместе |
| 23 | В браузере пройти регистрацию, вход через защищённый URL, выбор кабинета, оценку, прогноз, заявку и выход | Видны сообщения и результаты, выбранный кабинет восстановлен, отметка и заявка сохранены, после выхода снова требуется вход |
| 24 | Загрузить ASGI и WSGI, запустить CLI check, проверить расхождение миграций и диагностику отсутствующего Django | Обе точки входа доступны, системная проверка проходит, модели согласованы с миграциями, при отсутствии зависимости есть объяснение |
| 25 | Создать 20 учреждений и параллельно запросить каталог, пустой поиск, прогноз и форму заявки | Все 48 ответов имеют статус 200 и ожидаемый маркер содержимого |
| 26 | Запустить seed_data, превысить длину полей заявки, найти название строчными буквами, проверить типы опубликованных учреждений в фильтре | Ожидания и наблюдаемые расхождения приведены в BUG_REPORT.md. Шесть параметризованных примеров помечены строгим xfail |
| 27 | Дать раннему и позднему интервалам достаточную историю с разными средними | Побеждает менее загруженный поздний интервал |
| 28 | Отправить оценку в одной сессии без CSRF и с действительным токеном | В первом случае 403 и пустая таблица, во втором сохранена ровно одна отметка с верным владельцем |
| 29 | Войти с внешним значением next | Авторизованная сессия возвращается в локальный каталог |
| 30 | Открыть список заявок сотрудником только с правом просмотра | Публикация должна отсутствовать в действиях. Седьмой строгий xfail соответствует BUG-05 |
| 31 | Вернуть ошибку инициализации SDK карты в реальном браузере | Кнопка показывает недоступность карты, список учреждений остаётся видимым |
| 32 | Проверить обе стороны географических пределов и неизвестный уровень очереди через full_clean | Граничные координаты допустимы, выход на 0,000001 и неизвестный choice отклоняются нужным полем |
| 33 | Задать валидный график 10:30–11:15 | Ошибки нет, полных часовых интервалов и рекомендации нет |
| 34 | Выполнить HEAD пяти публичных страниц и GET неизвестного пути | Публичные страницы отвечают 200 без тела, неизвестный путь — 404 |
| 35 | Открыть мобильный каталог в браузере | Язык документа — ru, skip-link ведёт к main, присутствует один h1, фильтры имеют доступные имена |

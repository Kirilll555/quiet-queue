## Что означает полное покрытие Python

Проверены настройки покрытия, область сбора и места применения подмен. Coverage измеряет manage.py, config и pages, включая миграции. Исключён только каталог пустых прежних тестов. В прикладном коде не добавлялись pragma, фиктивные вызовы и обходные условия. Декларативные строки моделей, маршрутов, настроек и миграций покрываются в том числе при импорте. Исполнение этих строк само по себе не доказывает правильность связей или разграничения прав.

Большинство сценариев используют реальные модели, ограничения SQLite, сервисы, middleware, сессии и шаблоны. Управляемые часы нужны для границ свежести. Другие подмены ограничены сбоем записи, ошибкой хранилища, отсутствием Django и браузерным SDK карты. Ускоренный хешер применяется лишь в тестовой конфигурации. Качество производственного хеширования и поведение действующего API карт из этих результатов не следуют.

## Пробелы и ограничения

- Исходный набор покрывал гостя, обычного пользователя и администратора. Между ними отсутствовала проверка сотрудника с правом только просмотра, что скрывало BUG-05. Для комбинаций индивидуальных прав изменения заявки и добавления учреждения требуется согласованная ролевая матрица.
- В форме предложения список типов ограничен интерфейсом, сервер проверяет наличие непустого значения. Ограничения длины заданы моделью и проверены. Допустимость произвольного пользовательского типа требует решения команды.
- SEARCH и фильтрация категорий проверяются на SQLite. Другие СУБД и перенос схемы со старой рабочей базы с данными в прогон не входят.
- Основание BUG-04 — согласованность доступных при предложении и фильтрации типов. Формального перечня обязательных фильтров команда не предоставила. Основание BUG-01 — обнаруженная команда должна запускаться; состав демоданных не определён.
- Тесты ошибок хранилища подтверждают откат и реакцию обработчика. Гарантия отсутствия гонок при всех возможных чередованиях потоков требует большего, чем несколько локальных прогонов.
- Полноценная проверка WCAG, Safari, Firefox, визуальные регрессии, все обработчики отказов localStorage и точность прогноза на реальных данных остаются открытыми областями. Метрика функций JavaScript не измеряет отдельные условия внутри функций.
- Для времени отклика и пропускной способности нет согласованного SLO. Тест — короткая проверка корректности чтения под параллельной нагрузкой. Четыре потока, фиксированные 20 учреждений и 48 запросов не дают предельной ёмкости, длительной устойчивости и профиля рабочей нагрузки. Тайм-аут клиента 10 секунд ограничивает зависание. p95 вычисляется по ближайшему верхнему рангу, включая чтение тела ответа.

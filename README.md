## 🚀 Быстрый старт (Запуск проекта)

Выполните эти шаги, чтобы проект заработал на вашем компьютере.

**1. Клонирование репозитория:**

    git clone <ссылка-на-ваш-репозиторий>
    cd quiet_queue

**2. Создание и активация виртуального окружения (Windows):**

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1

**3. Установка зависимостей:**

    python -m pip install --upgrade pip
    python -m pip install django

**4. Применение миграций (создание служебной БД):**

    python manage.py migrate

**5. Запуск сервера:**

    python manage.py runserver

После запуска сайт доступен по адресу: **http://127.0.0.1:8000/**

*(Окно терминала закрывать нельзя, пока вы тестируете сайт. Остановить сервер — `Ctrl + C`).*

## 🎨 Инструкция для Frontend-разработчика

Все стили пишутся в папке `static/css/`. Файлы уже созданы и подключены к нужным страницам в HTML-коде.

* `base_styles.css` — стили для меню, футера и общих элементов (подключается на всех страницах).
* `index_styles.css` — стили только для главной страницы (`/`).
* `rate_styles.css` — стили для страницы оценки (`/rate/`).
* `suggest_styles.css` — стили для страницы предложки (`/suggest/`).
* `ai_styles.css` — стили для страницы прогноза ИИ (`/ai-prediction/`).

## 🕵️‍♂️ Инструкция для Тестировщика (QA)

Для автотестов создана папка `pages/tests/`. Пишите код в файле `test_views.py`.

В терминале (с активированным `.venv`) выполните:

    python manage.py test
